**JointEdit3D** performs feed-forward 3D scene editing in a unified RGB-geometry latent space. Given a source video and a single edited reference frame, it generates edited RGB views and 3D geometry while preserving unedited scene content.

The work introduces **SceneEdit3D-15K**, a paired scene-editing dataset with renderer-provided 3D annotations, and **SceneEdit3D-Bench** for standardized evaluation.

**Release status:** SceneEdit3D-15K is publicly available. The repository currently provides project and dataset information; inference and training code, model weights, and data-generation scripts are planned for release upon paper acceptance.
